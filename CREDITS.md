# Credits

shipfitter is build and packaging helpers for Rust desktop apps. Fedra and Paperback (by trypsynth) use it. Most of its design follows what those apps already did by hand.

Third-party tools it drives:

- minisign for release signatures.
- Inno Setup and appimagetool (found on PATH, or downloaded and SHA-256-verified on first use).
- minisign and the platform code signers behind the `sign` module.

Questions and bug reports are welcome in the [SerrebiProjects Telegram group](https://t.me/SerrebiProjects). More serrebi projects: [projects.serrebiradio.com](https://projects.serrebiradio.com).
